# Security Assurance Operations Simulation

**Project Type:** Independent GRC Portfolio Project  
**Environment:** ClearPath Health Cloud (Fictional Healthcare SaaS Company)  
**Status:** Completed  
**Reporting Date:** November 13, 2026

## Project Objective

Simulate the daily responsibilities of a Security Assurance Analyst by managing customer security requests, coordinating security questionnaires, tracking audit evidence, documenting escalations, and reporting operational status.

## Project Deliverables

- **Security-Assurance-Tracker.xlsx:** Five worksheets covering request tracking, security questionnaires, audit evidence, escalations, and an operational dashboard.
- **Executive-Summary.pdf:** One-page management report identifying outstanding security assurance requests, evidence gaps, critical escalations, and recommended next steps.

## Project Results

- Tracked seven simulated customer security requests with priorities, owners, deadlines, and statuses.
- Documented five security questionnaire responses with evidence requirements and verification steps.
- Managed five simulated audit evidence requests, including incomplete and pending evidence.
- Recorded two escalations involving sensitive vulnerability disclosure and suspected customer data exposure.
- Developed an Excel dashboard summarizing request status and outstanding work.
- Prepared an executive summary highlighting key findings and management recommendations.

## Skills Demonstrated

- Security assurance request management
- Security questionnaire coordination
- Audit evidence tracking
- Escalation documentation
- Risk-based request prioritization
- Operational reporting and stakeholder communication

## Simulation Disclaimer

This is an independent educational simulation. All company details, requests, records, and stakeholder communications are fictional.

Evidence references are illustrative and do not link to actual supporting files. The project does not represent a real customer engagement, completed SOC 2 audit, or verified security control assessment.
