# Security Assurance Operations Simulation

**Project Type:** Independent GRC Portfolio Project
**Environment:** Fictional Healthcare SaaS Company
**Status:** In Progress

## Project Objective

Simulate the daily responsibilities of a Security Assurance Analyst by managing customer security requests, tracking audit evidence, coordinating security questionnaires, and documenting escalations.

## Project Deliverables

- Security Request Tracker (Excel)
- Customer Security Questionnaire (Excel)
- Audit Evidence Tracker (Excel)
- Escalation Log (Excel)
- Operational Dashboard (Excel)
- Executive Summary (PDF)

## Skills Demonstrated

- Security request intake and prioritization
- Audit evidence tracking
- Security questionnaire coordination
- Issue escalation and documentation
- Operational reporting

## Disclaimer

This project is a fictional educational simulation. All company details, requests, and evidence are simulated. It does not represent an actual security assessment, audit, or professional engagement.
